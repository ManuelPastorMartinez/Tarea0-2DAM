# Mutxa-ECO

Mi propuesta consiste en una aplicación que permita ver un mapa con las papeleras y contenedores de reciclaje de Mutxamel y que los usuarios puedan ir añadiendo nuevas papeleras para que el administrador las valide. También he pensado en un sistema de puntos por cada papelera o contenedor que se valide en el mapa. Una papelera serían 50 puntos y un contenedor 200. Estos puntos se podrían ir canjeando por recompensas sencillas para motivar a la gente a que escanee nuevas papeleras para el mapa y cada vez esté más completo.
